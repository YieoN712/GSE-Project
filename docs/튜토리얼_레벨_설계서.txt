GSE Project 튜토리얼 레벨 설계서 v0.1
작성일: 2026-09-09
레벨명(가칭): 늘 앉던 자리
상태: 구현 전 설계. 플레이 시간과 화면 품질은 실제 실행으로 검증해야 한다.

1. 목표와 범위

작은 동네에서 WASD 이동, 주민과 상호작용, 짧은 퀘스트를 체험한다.
따뜻하고 살아 있는 현대 동네를 먼저 보여주고, 마지막에 기억의 어긋남을 암시한다.
메인 이야기의 실종 사건 이전에 배치할 수 있는 독립적인 프롤로그 조각이다.
주요 인물 윤의 실종이나 관리국의 정체를 이 구간에서 설명하지 않는다.

목표 소요 시간은 최초 플레이 기준 3분 30초~4분 30초, 여유 포함 5분 이내이다.
이는 정상적인 목표 진행 기준이며, 무제한 배회나 장시간 대기까지 포함한 강제 제한은 아니다.
5분이 되었다고 실패시키지 않는다. 검증 때 일시정지 시간은 제외해 기록한다.
이번 범위는 동네 한 구역, 주민 8명, 필수 퀘스트 1개, 이상 현상 1개이다.
전투, 인벤토리 화면, 장비 성장, 전체 하루 순환, 던전과 월드 스트리밍은 후속 범위다.

2. 조작

W / A / S / D: 화면 기준 위 / 왼쪽 / 아래 / 오른쪽 방향으로 지면 이동.
카메라의 지면상 전방·오른쪽 벡터로 변환한다. 월드 X-Z 평면, 높이 Y를 유지한다.
대각선 입력은 정규화해 더 빨라지지 않도록 한다. 기본 이동 속도는 초당 3.5m 후보.
E: 대화, 받기, 전달, 조사 및 대화 다음 문장. 누른 순간에 한 번만 처리한다.
Tab: 현재 목표와 조작 안내 표시/닫기.
Esc: 일시정지 메뉴. 계속하기와 튜토리얼 다시 시작 제공.
달리기와 점프, 마우스 클릭 이동은 이번 구간에 필요하지 않다.

상호작용은 약 1.5m 안에서 가장 가까운 유효 대상 한 명/한 개에만 적용한다.
동일 거리에서는 바라보는 방향에 가까운 대상을 우선한다.
대상에게 외곽선과 'E 대화 / E 받기 / E 전달 / E 조사'를 표시한다.
벽 너머 대상은 선택하지 않는다. 대화 중 이동 입력은 잠시 막고 대상도 멈춘다.
직전 E 입력으로 다음 대사나 다음 퀘스트까지 한꺼번에 진행되지 않게 한다.

3. 공간 구성

월드 크기 후보: 약 48m x 36m. 외부 거리만 플레이 가능하며 실내 진입은 없다.
집 앞 → 빵집 → 작은 쉼터 → 골목 게시판 → 쉼터의 고리 동선을 사용한다.
출발점과 빵집은 처음 화면에 함께 보이고, 다음 목적지는 거리 표식으로 안내한다.
필수 이동 거리는 장애물 우회 포함 약 110~140m, 순수 이동 약 32~40초를 목표로 한다.
전체 맵이 항상 한 화면에 들어가지는 않는다. 화면에는 통상 주민 3~5명이 보인다.

배치 개념도(월드 배치, 실제 카메라 투영 화면은 아님):

  [주거 건물]        [게시판 / 돌아가는 골목]      [주거 건물]
       |                       |                      |
  [집 앞: 시작] ------ [작은 쉼터: 벤치] -------- [화단]
       |                       |                      |
  [빵집: 퀘스트] ----- [동네 길 / 주민 이동] ------ [편의점 외관]

배경 건물, 화단과 낮은 담으로 경계를 자연스럽게 닫는다.
주요 길은 약 3~4m 폭을 확보하고 길을 막는 주민은 배치하지 않는다.
퀘스트 주민은 고정 지점에 두며, 보행 주민은 플레이어와 겹치더라도 진행을 막지 않는다.
건물 뒤로 들어가 목표나 플레이어가 완전히 가려지는 동선은 만들지 않는다.

4. 주민 8명

1) 빵집 주인: 필수 퀘스트 제공. 가게 앞에서 빵 진열 동작.
2) 벤치의 어르신: 필수 전달 대상. 처음에는 앉아 있고 전달 후 감사 인사.
3) 청소하는 이웃: 시작점 가까이에서 쓸기. 선택 대화 1문장.
4) 화분을 돌보는 주민: 물주기 반복. 선택 대화 1문장.
5) 배달원: 편의점과 빵집 사이의 짧은 경로 순환.
6) 학생: 골목과 쉼터 사이를 천천히 걷는다.
7) 편의점 앞 주민: 진열품 정리 또는 휴대전화 보기.
8) 쉼터의 이웃: 나무 옆에 서 있다. 마지막 이상 현상의 대사를 담당한다.

필수 대화 대상은 1, 2, 8번이다. 다른 5명은 짧은 인사와 동작으로 생활감을 만든다.
복잡한 일일 스케줄 대신 위치 고정 동작과 짧은 웨이포인트 순환으로 구현한다.
실루엣, 옷 색, 소품으로 구분한다. 주민 전원을 같은 색의 도형으로 표시하지 않는다.

5. 필수 퀘스트: 식기 전에

핵심 경험: 작은 심부름으로 누군가의 일상에 참여하고, 방금 만든 기억을 의심하게 된다.
빵 봉투는 화면의 작은 소지 표시로만 표현한다. 별도 아이템 창을 열지 않는다.

단계 0 / 집 앞 / 0:00~0:25
WASD 안내가 표시된다. 조금 이동하면 빵집 주인 위에 상호작용 표시가 나타난다.
목표: '빵집 사장님에게 인사하기'.

단계 1 / 빵집 / 0:25~0:55
E로 대화하고 빵을 받는다.
사장: '벤치에 계신 어르신께 이것 좀 전해 줄래? 오늘도 기다리고 계실 거야.'
사장: '늘 같은 시간에 오시거든. 식기 전에 부탁해.'
목표가 '쉼터의 어르신께 빵 전달하기'로 변경된다.
'식기 전에'는 이야기 표현이며 소멸 타이머나 실패 조건은 없다.

단계 2 / 동네 길 / 0:55~1:35
생활 동작 중인 주민을 지나 쉼터로 이동한다. 선택 인사를 할 여유를 둔다.
어르신과 빈 옆자리가 함께 보인다. 작은 손수건이 벤치 옆자리에 놓여 있다.

단계 3 / 쉼터 / 1:35~2:05
E로 빵을 전달한다. 봉투 표시가 사라진다.
어르신: '오늘도 잊지 않았구나. 고맙다.'
어르신: '누군가 기다린다는 건 참 좋은 일이야.'
어르신: '돌아가는 길에 게시판의 동네 사진도 보고 가렴.'
목표가 '골목 게시판의 동네 사진 보기'로 변경된다.

단계 4 / 게시판 / 2:05~2:45
E로 작은 동네 사진을 본다. 벤치에 어르신이 앉아 있는 단순한 사진이다.
주인공 독백: '늘 지나가던 곳인데, 이렇게 보니 조금 다르다.'
창을 닫으면 쉼터 방향의 짧은 소리와 목표가 나타난다.
목표: '쉼터에서 들린 소리 확인하기'.
사진은 소규모 2D 일러스트/아이콘 자산으로 제작 가능하며 촬영 시스템은 필요 없다.

단계 5 / 쉼터 / 2:45~3:35
게시판을 보는 동안 어르신이 자리를 떠난다. 화면 앞에서 갑자기 삭제하지 않는다.
벤치에는 빵 봉투와 손수건이 남아 있고, 사람 모양의 그림자가 약 2초 뒤늦게 사라진다.
플레이어가 쉼터 조사 지점에 접근했을 때 연출을 시작해 이동 중 놓치지 않게 한다.
그림자를 보지 못해도 E 조사와 다음 대사로 이상을 알 수 있어야 한다.
쉼터 이웃: '어르신? 오늘 저 벤치에는 아무도 없었는데.'
주인공 독백: '분명 방금 이야기를 나눴는데….'
이 현상이 실제 영구 소실인지는 밝히지 않는다. 메인 세계관의 복구 규칙도 확정하지 않는다.

단계 6 / 완료 / 3:35~4:00
'기억 기록: 오늘 빵을 건넨 사람'을 획득한다.
완료 문구: '당연했던 하루에, 기억하고 싶은 일이 생겼다.'
튜토리얼 완료 화면에서 다시 시작 또는 동네 둘러보기를 선택한다.
완료 후 둘러보기는 튜토리얼 목표 플레이 시간에서 제외한다.

표준 진행 예산은 약 4분이며, 짧은 선택 대화와 길 찾기 여유 약 30~60초를 둔다.
대사는 한 번에 1~2줄, E로 즉시 넘길 수 있게 한다. 필수 장문 설명은 넣지 않는다.

6. 퀘스트 상태와 안정성

미수락 → 빵 소지 → 전달 완료 → 사진 확인 → 쉼터 이상 확인 → 완료.
단계마다 현재 목표는 한 개만 표시한다.
수락 전 어르신은 인사만 하고, 사진을 먼저 조사하면 일반 사진 설명만 보여준다.
중복 E로 빵을 여러 개 받거나 보상이 반복 지급되지 않도록 상태로 제한한다.
전달 후에만 게시판 조사가 다음 단계로 이어진다.
사진 확인 후 어르신은 필수 상호작용 대상에서 제외되며, 이웃과 벤치가 진행을 담당한다.
30초 동안 목표 진행이 없으면 목표 표식을 부드럽게 강조한다. 자동 진행은 하지 않는다.
다시 시작 시 주민 위치, 그림자, 봉투, 기록과 퀘스트 단계를 모두 초기화한다.

7. 렌더링 목표

초여름 늦은 오후의 동네를 유지한다. 5분 안에 억지로 낮밤 전체를 순환시키지 않는다.
고정 직교 쿼터뷰: 수평 회전 약 45도, 내려다보는 각도 약 35도를 초기값으로 삼는다.
플레이어를 부드럽게 추적하고 맵 가장자리에서는 카메라를 제한한다.
카메라 회전과 줌 조작은 이번 프로토타입에서 생략한다.

표현 요소:
- 아이보리 벽, 벽돌·살구색 지붕, 녹색 화단, 청록색 차양으로 따뜻한 기본 색을 만든다.
- 낮은 3D 건물과 지면에 캐릭터 스프라이트 또는 단순 메시를 배치한다.
- 깊이 테스트로 앞뒤를 처리하고 캐릭터 발밑 그림자로 접지감을 준다.
- 방향광과 환경광으로 면의 밝기 차이를 만든다.
- 낮은 담, 차양, 벤치, 화분, 가로등, 간판, 빨래와 빵 진열로 현대 생활감을 준다.
- 나뭇잎·빨래의 미세한 흔들림과 주민 동작으로 정적인 모형처럼 보이지 않게 한다.
- 고해상도 그림자맵은 필수 아님. 단순 투영 그림자도 분위기 검증에 사용할 수 있다.

마지막 이상 현상:
동네 전체의 밝기는 유지한다. 벤치 주변만 약간 차가운 색으로 바꾸고 비정상 그림자를 둔다.
섬광, 전체 암전, 점프 스케어 없이 밝은 화면 안의 어긋남을 보여준다.
구현 시 정상 쉼터 장면과 이상 현상 장면 두 화면으로 표현 차이를 확인할 수 있어야 한다.
이번 문서는 렌더링 목표를 정의한 것이며 실제 렌더링 결과물은 아직 제작하지 않았다.

음향 후보:
주민의 생활 소리, 새소리, 가게 종과 가벼운 배경음.
이상 현상에서는 생활 소리를 잠깐 줄이고 짧은 불협화음을 넣는다.
진행 단서는 소리에만 의존하지 않고 목표 문구와 화면 연출로도 제공한다.

8. 최소 구현 순서

1) 고정 쿼터뷰, 깊이 표현, WASD 화면 기준 이동과 건물 충돌.
2) 동네 배치, 주민 8명과 짧은 생활 동작.
3) E 대상 선택, 한국어 대사 표시, 단일 목표 UI.
4) 빵 전달부터 사진 조사까지의 상태 진행.
5) 벤치의 이상 현상과 기억 기록, 완료/재시작.
6) 색·광원·소품·그림자를 다듬어 정상/이상 장면의 분위기 차이 확보.

9. 사용자 플레이 확인 기준

- WASD 이동이 화면 방향과 맞고 대각선이 빠르지 않은가.
- E 대상이 명확하며 주민과 벽 때문에 진행이 막히지 않는가.
- 주민 8명이 존재하고 이동·생활 동작으로 동네가 살아 있다고 느껴지는가.
- 목표만 따라 최초 정상 진행을 5분 이내에 완료할 수 있는가.
- 대사를 읽고 선택 인사 1~2회를 해도 시간 예산 안에 들어오는가.
- 정상 화면은 따뜻하고, 마지막 화면은 밝기를 유지하면서 불길한가.
- 반복 상호작용과 순서 밖 조사에서도 진행이 깨지지 않는가.
- 재시작하면 모든 상태가 초기 상태로 돌아오는가.

시간 측정이 5분을 넘으면 걷는 속도부터 높이지 않고 대사 길이, 목표 가시성,
불필요한 왕복 순서로 조정한다. 빌드와 실제 플레이·화면 결과 확인은 사용자가 수행한다.
