튜토리얼 렌더링·동네 개선 v2

기존 SimpleGame 프로젝트를 업데이트했다. 퀘스트·조작·한국어 UI는 유지한다.

렌더링
- RenderEffects.h/cpp에 그림자, 머터리얼, 후처리 리소스와 패스를 분리했다.
- 방향광 기준 2048 x 2048 깊이 그림자맵, 5 x 5 PCF 필터 및 표면 각도별 바이어스.
- 캐릭터와 건물, 나무의 실제 메시가 그림자 패스에 참여한다.
- 창 크기에 맞는 화면 렌더 타깃과 깊이 버퍼를 사용하며 리사이즈·종료 시 해제한다.
- 후처리: 경계 기반 간단한 안티앨리어싱, 약한 밝은 영역 번짐, 따뜻한 색조, 비네트.
- UI는 후처리 이후 출력해 글자가 흐려지는 것을 방지한다.
- 길은 아스팔트 입자, 보도는 줄눈, 잔디는 색 변화와 미세 패턴으로 표현한다.
- 벽돌 외벽, 금속 지붕, 유리창, 목재와 옷감의 패턴·반사 강도를 구분한다.
- 머터리얼은 셰이더 기반 절차적 표현이며 외부 텍스처/PBR 자산은 아니다.
- FBO 미지원 또는 셰이더 실패 시 콘솔에 원인을 출력하고 호환 렌더링으로 돌아간다.

캐릭터
- 머리·머리카락·눈·코·몸통·팔·손·다리·신발을 둥근 메시로 세분화했다.
- 이동 방향에 따라 회전하고 실제 이동 거리에 맞춰 팔다리와 몸의 보행을 표현한다.
- 멈추면 보행을 멈추며 호흡 정도의 작은 움직임을 유지한다.
- 플레이어가 실제로 이동한 거리마다 짧은 먼지 효과를 생성한다.
- 스프라이트 시트 애니메이션은 추가하지 않았다. 이번 버전은 메시 애니메이션이다.

맵과 주민
- 맵 4배는 면적 기준이다. 가로·세로가 각각 2배인 88 x 64 범위를 이동한다.
- 외곽 건물 12채, 도로·보도·수목을 추가하고 카메라와 충돌 경계도 확장했다.
- 5분 이내 퀘스트를 위해 빵집, 어르신, 게시판, 쉼터 이웃 위치는 유지했다.
- 상호작용 대상은 퀘스트 주민 3명과 게시판·벤치이다.
- 나머지 주민 5명은 상호작용 없이 초당 약 0.65 단위로 천천히 배회한다.
- 배회 중 건물 또는 경계를 만나면 방향을 바꾸고, 거점에서 약 7단위 이내에 머문다.
- 재시작 시 위치·방향·보행 위상·먼지 등도 초기화된다.

사용자 확인
1. 기존 구성으로 빌드 후 콘솔에 셰이더/FBO 실패 메시지가 없는지 확인.
2. 건물·나무·캐릭터의 그림자 방향과 가장자리, 걷는 동안의 그림자를 확인.
3. 길·보도·잔디·벽·유리의 재질 구분과 UI 글자 가독성을 확인.
4. 이동 때만 발밑 효과와 팔다리 애니메이션이 발생하는지 확인.
5. 상호작용 불가 주민이 벽 안에 들어가거나 퀘스트를 가로막지 않는지 확인.
6. 외곽 길과 건물까지 이동한 뒤 기존 퀘스트를 완료할 수 있는지 확인.
7. 창 크기 변경, 일시정지와 재시작, 종료를 확인.

이번 변경은 정적 코드·프로젝트 확인만 수행했다. 빌드·실행·화면 비교·성능 측정은
사용자에게 맡긴다. 시각 품질과 프레임 성능은 아직 실행으로 검증되지 않았다.
기존 튜토리얼_구현_확인.txt의 렌더링·크기·주민 동작 설명은 이 v2 문서가 대체한다.
