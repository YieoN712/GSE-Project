# 레벨 1 · 동네와 외곽

- 중앙 반경 18: 생활 구역. 18~24: 경계. 24 이상: 외곽. 몹은 26 이상에서 생성되고 마을로 들어오지 않습니다.
- 주민 8명이 연결된 길을 따라 걷고 쉽니다. 중앙에 상점·주거·공동 주택·시설 랜드마크를 배치합니다.
- E: 가까운 주민과 대화 우선, 없으면 아이템 획득. Tab: 동네 기록(진행 정지). Esc: 기록 닫기.
- 처음 인사한 주민마다 신뢰 +1. 외곽 잔향 3마리마다 빵집 사장에게 소식을 전하면 신뢰 +2, 최대 6회.
  반복 인사·같은 소식으로 중복 보상하지 않습니다. 평판은 선악이 아닌 동네에서 쌓은 신뢰입니다.
- 대화로 소문을 듣고 외곽 보고 후 안심하는 소문·분위기가 추가됩니다. 모니터에도 실제 상태를 제공합니다.
- 새 맵/재실행 시 사회 진행도도 초기화합니다. 정식 하루 일정·NPC 전투·저장은 아직 없습니다.

수동 확인: 산책 → E 인사 → Tab 기록 → 외곽 사냥 → 빵집 보고 → 모니터 평판/소문 변화 확인.
몬스터를 유인해도 마을로 못 들어오는지, 여러 시드에서 주민 경로가 막히지 않는지 확인해 주세요.
C++ 회귀 검사 소스에 주민 배치·이동 경계·인사/보고 중복 방지·초기화 검사를 추가했습니다.
빌드·게임 실행 확인은 사용자 수행입니다.
